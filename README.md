## 🚀 Как запустить тесты локально

Если вы хотите склонировать репозиторий и запустить тесты у себя:

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:ВАШ_НИКНЕЙМ/ИМЯ_РЕПОЗИТОРИЯ.git
   ```
2. **Перейдите в папку проекта:**
   ```bash
   cd ИМЯ_РЕПОЗИТОРИЯ
   ```
3. **Установите зависимости (если есть файл requirements.txt):**
   ```bash
   pip install -r requirements.txt
   ```
4. **Запустите тесты:**
   ```bash
   pytest
   ```
